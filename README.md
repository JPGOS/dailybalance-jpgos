# dailybalance-jpgos

饮食、运动与每日能量平衡记录工具。当前在线版与安卓版本为 **1.5.5**。

[在线使用](https://meal-balance-jpgos.jpgosyoung.chatgpt.site/) · [安装与使用说明](docs/INSTALL_AND_USAGE.md)

## 功能

- 103 种内置食物、分类与图片，支持自定义食物和营养编辑。
- 24 种运动，按 MET、体重、时长估算额外运动净消耗。
- 根据身高、体重、性别、年龄估算日常基准，也支持手动填写。
- 每日热量与营养汇总；蓝色缺口、橙色盈余。
- 全年热量日历、近14日折线图、自选时间范围分析。
- 当前年份日历默认定位到当前月份，其他年份从一月开始，月份顺序不变。
- 右上角设置左侧的太阳 / 月亮按钮可切换浅色和深色，自动保存主题偏好。
- JSON 备份、恢复、CSV 导出，本地保存个人记录。
- 在线版支持添加到主屏幕和静态资源离线缓存。

## 目录

| 目录 | 内容 |

| `web/` | 已发布的网页版及图标、离线缓存 |

## 本地运行网页版

在项目根目录运行：

```sh
python -m http.server 8000 --directory web
```

打开 `http://localhost:8000`。正式部署使用 HTTPS，才能启用主屏幕应用和 Service Worker。每个人的记录保存在自己的浏览器中，网站不保存用户的饮食或身体资料。

## 安卓构建

`android/build-apk.ps1` 是当前使用的 Windows 构建脚本。需要准备 Java、Android SDK 平台35、构建工具、D8和 apksigner，并按脚本设置本机路径。SDK、构建产物和签名资料不随仓库上传。

首次构建可生成本地签名密钥。若要升级已经安装的版本，必须使用原有签名密钥；原密钥应私下安全备份，不能提交到仓库。

## iOS 构建

打开 `ios/DailyBalance.xcodeproj`。需要 Mac/Xcode或云端Mac，并配置自己的 Apple 开发者签名。当前工程尚未完成 iOS 编译和真机测试，不是可直接安装的 IPA。详见 [iOS 工程说明](ios/README.md)。

## 数据和素材

热量和营养数据包含同类食物参考与配方估算，应按包装标签或实际配方调整。自动基准按成年人公式估算，不属于医疗建议。

食物照片来源及具体许可见 [图片来源与许可](web/photo-credits.html)。USDA营养参考和补充配方的生成代码位于 `android/`。

仓库不包含个人记录、开发者账号凭据、Sites发布凭据或安卓签名密钥。已有APK请通过单独的安装文件分享，避免把多个历史安装包提交到源码仓库。
