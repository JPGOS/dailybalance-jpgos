# DailyBalance 安装与使用说明

版本：1.5.3  
更新时间：2026-10-13

## 在线使用与分享

网站地址：[打开 DailyBalance](https://meal-balance-jpgos.jpgosyoung.chatgpt.site/)

通过这个链接即可打开，不需要购买 Apple 开发者账号，也不需要安装 ChatGPT。网站已设置为公开访问。每个人的饮食、运动及个人资料保存在自己的浏览器或应用中，分享链接不会分享个人记录，也不会自动同步记录。

## iPhone：添加到主屏幕

1. 复制网站链接，在 **Safari** 中打开。避免一直在微信或聊天软件的内置浏览器中使用。
2. 首次打开时保持联网，等待页面和图片加载。
3. 点击 Safari 的“分享”按钮，选择 **添加到主屏幕**。如果没有看到，在分享菜单中查看“编辑操作”。
4. 名称填写 **DailyBalance**。如果系统显示“作为网页 App 打开”，将它打开，然后点击“添加”。
5. 此后点击桌面的蓝橙方格图标使用。建议添加完成后，从桌面入口开始正式记录。

这是主屏幕网页版，不是 IPA 或 App Store 应用。Safari 与主屏幕入口、不同浏览器的存储空间可能不同；已有数据应先导出备份，再在常用入口导入。

Apple 官方说明：[将网站变成 iPhone 网页 App](https://support.apple.com/en-eg/guide/iphone/iphea86e5236/ios)

## 安卓：两种使用方式

### 在线网页版

在 Chrome 或手机浏览器中打开网站，从浏览器菜单选择“添加到主屏幕”或“安装应用”（文字依浏览器而异），名称保留 DailyBalance。

### 安卓安装包

使用单独提供的 **DailyBalance-1.5.3.apk**，支持安卓 8.0 及以上。

1. 将 APK 下载到手机并打开。
2. 如果手机提示，允许当前文件管理器或浏览器安装此文件。
3. 按系统提示完成安装，桌面名称为 DailyBalance，图标为蓝橙方格。
4. 同一签名的新版可以按系统提示升级。升级前建议先导出备份。

APK 与网页版的数据独立，需要通过 JSON 备份迁移。APK 没有自动更新功能。

## 第一次设置

1. 打开右上角的 **我的设置**。
2. 填写身高、体重、性别和年龄。
3. 使用“自动估算”或选择“手动填写”日常消耗基准，点击保存。

自动模式使用 Mifflin–St Jeor 静息消耗公式乘以 1.2，默认按久坐、少量日常活动估算，适用于成年人。额外运动另行累计。该结果是估算值，不是设备测量值。

## 记录饮食

1. 确认页面上方的记录日期。
2. 点击“记录饮食”或底部“食物库”。
3. 搜索或按分类选择食物，点击“＋”。
4. 选择餐次、填写摄入量和单位，然后保存。

按克或毫升记录时，热量按每 100 单位的数据换算；按“份”记录时，使用食物资料中的默认份量。

热量、碳水、蛋白质、脂肪、膳食纤维及钠均可在 **营养详情 / 编辑** 中修改。已有历史记录保留保存时的数据。

库中没有的食物可以通过“添加自定义食物”创建，填写名称、分类、每百克或毫升热量、营养成分和默认份量，并可添加自己的照片。内置数据含同类食物参考及配方估算，应按包装或实际配方调整。

## 记录运动

1. 点击“记录运动”或底部“运动库”。
2. 选择与实际活动、强度相近的项目。
3. 填写时长和体重，保存记录。

MET 数值以紫到黄的渐变区分强度。应用估算的是额外运动净消耗，已扣除同时间的静息消耗；日常基准中已包含的活动不必重复记录。

## 查看当天能量与营养

首页显示摄入、运动净消耗、全天估算消耗及摄入减消耗。

- 摄入数值为绿色，运动消耗数值为莓红色。
- 差额为负代表热量缺口，使用蓝色；为正代表盈余，使用橙色。
- 每日营养摄入按保存的食物记录汇总。

记完当天饮食和运动后，勾选 **我已记完今天的饮食与运动**。完整记录才会参与趋势与时段分析；消耗和热量差额还需设置日常基准。

## 历史、14 日趋势与时段分析

- 热量日历每格一天，每列一周。蓝色表示缺口、橙色表示盈余，深浅表示数量。点击方格可查看当天明细。
- “近14日”以页面上方选定日期为结束日期，含当天。折线图分别表示摄入、全天消耗和热量差额。
- 在“时段分析”选择开始及结束日期，点击“分析”，或使用近14、30、90日快捷按钮。
- 结果包含日平均摄入、日平均消耗、日平均热量差额、累计差额、折线图和文字小结。
- 未记录或未确认完整的日期不会按零摄入计算。长时段图可左右滑动。

## 备份、恢复与迁移

在 **我的设置 → 数据与隐私** 中：

- **导出完整备份**：下载 JSON 文件，建议保存到“文件”、iCloud Drive 或电脑。
- **导入备份**：选择 JSON 文件。导入会替换当前记录，应先备份。
- **导出记录 CSV**：在历史页导出，便于查看和整理；CSV 不是完整恢复备份。

从安卓 APK、单文件 HTML 或另一个浏览器迁移时，先在原入口导出完整 JSON，再在新入口导入。不同用户应分别使用自己的备份文件。

## 离线、更新及常见问题

- 在线版首次访问需要联网。静态页面和图片缓存完成后可支持离线使用；缓存被清理、首次下载未完成或浏览器限制缓存时，需要重新联网。安卓 APK 的页面和图片随安装包提供。
- 网站更新后可能仍显示旧缓存。先导出备份，再关闭 DailyBalance 所有窗口并重新联网打开。不要为了更新直接清除浏览器数据。
- 图片或按钮在微信预览中不正常：复制链接到 Safari 或 Chrome 打开。
- 数据突然为空：确认使用的是原来的浏览器、网址和入口；无痕模式不适合长期保存记录。
- iPhone 的“文件”应用预览本地 HTML 不能保证完整功能，优先使用上面的在线链接。

数据只保存在本机。清除浏览器数据、删除应用或设备损坏都可能造成记录丢失，请定期备份。
